# AnglerProduct

The product object that the product variant belongs to.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `id` | string | The ID of the product. |
| `title` | string | The product’s title. |
| `untranslatedTitle` | string | The product’s untranslated title. |
| `vendor` | string | The product’s vendor name. |
| `type` | string | The product type specified by the merchant. |
| `url` | string | The relative URL of the product. |
