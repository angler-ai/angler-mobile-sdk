# AnglerSearchResult

A search the shopper ran, sent with `search_submitted`.

Sent as `data.searchResult`. Usually sent with `search_submitted`.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `query` | string | The search query that was executed. |
| `productVariants` | list of [AnglerProductVariant](../product-variant/README.md) | The variants the search returned; the first page is enough. |

## Example

**Swift**

```swift
Angler.track(
    .searchSubmitted,
    data: AnglerData(
        searchResult: AnglerSearchResult(
            query: "linen",
            productVariants: [
                AnglerProductVariant(id: "41234567890"),
                AnglerProductVariant(id: "41234567891")
            ]
        )
    )
)
```
