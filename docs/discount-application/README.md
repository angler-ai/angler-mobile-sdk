# AnglerDiscountApplication

Discount applications capture the intentions of a discount source at the time of application.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `allocationMethod` | string | The method by which the discount's value is applied to its entitled items. |
| `targetSelection` | string | How the discount amount is distributed on the discounted lines. |
| `targetType` | string | The type of line (i.e. line item or shipping line) on an order that the discount is applicable towards. |
| `title` | string | The customer-facing name of the discount. If the type of discount is a DISCOUNT_CODE, this title attribute represents the code of the discount. |
| `type` | string | The type of the discount. |
| `value` | [AnglerDiscountApplicationValue](../discount-application-value/README.md) | The value of the discount. |

## Example

**Swift**

```swift
let discountApplication = AnglerDiscountApplication(
    allocationMethod: "ACROSS",
    targetSelection: "ALL",
    targetType: "LINE_ITEM",
    title: "SUMMER10",
    type: "DISCOUNT_CODE",
    value: .pricingPercentageValue(AnglerPricingPercentageValue(percentage: 10))
)
```
