# AnglerInventoryItem

The inventory item associated with the product variant, including its per-item cost (COGS).

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `id` | string | Inventory item identifier. Optional; for Shopify shops this is the inventory_items.id. For non-Shopify, may equal variant.id. |
| `cost` | [AnglerMoney](../money/README.md) | A monetary value with currency representing the unit cost to manufacture, distribute, and sell the item. |
