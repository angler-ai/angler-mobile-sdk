# AnglerDiscountAllocation

An amount discounting the line that has been allocated by a discount.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `amount` | [AnglerMoney](../money/README.md) | A monetary value with currency. |
| `discountApplication` | [AnglerDiscountApplication](../discount-application/README.md) | Discount applications capture the intentions of a discount source at the time of application. |

## Example

**Swift**

```swift
let discountAllocation = AnglerDiscountAllocation(
    amount: AnglerMoney(amount: 5.9, currencyCode: "USD"),
    discountApplication: AnglerDiscountApplication(
        title: "SUMMER10",
        type: "DISCOUNT_CODE",
        value: .pricingPercentageValue(AnglerPricingPercentageValue(percentage: 10))
    )
)
```
