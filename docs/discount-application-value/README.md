# AnglerDiscountApplicationValue

The value of a discount: a percentage (`AnglerPricingPercentageValue`) or a fixed amount (`AnglerMoney`).

[All data objects](../README.md)

## One of

- [AnglerMoney](../money/README.md)
- [AnglerPricingPercentageValue](../pricing-percentage-value/README.md)

In Swift it's an enum with a case per type; in Kotlin and Dart both types implement it; in TypeScript it's a union of the two.

## Examples

### AnglerPricingPercentageValue

**Swift**

```swift
let discountApplicationValue: AnglerDiscountApplicationValue = .pricingPercentageValue(AnglerPricingPercentageValue(
    percentage: 10
))
```

```kotlin

    percentage = 10,

```


**Flutter (Dart)**

