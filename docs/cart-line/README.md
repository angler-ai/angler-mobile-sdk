# AnglerCartLine

Represents information about the merchandise in the cart.

Sent as `data.cartLine`. Usually sent with `product_added_to_cart`, `product_removed_from_cart`.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `cost` | [AnglerCartLineCost](../cart-line-cost/README.md) | The cost of the merchandise line that the buyer will pay at checkout. |
| `merchandise` | [AnglerProductVariant](../product-variant/README.md) | Product variant of the line item. |
| `quantity` | number | The quantity of the merchandise that the customer intends to purchase. |

## Example

**Swift**

```swift
Angler.track(
    .productAddedToCart,
    data: AnglerData(
        cartLine: AnglerCartLine(
            cost: AnglerCartLineCost(totalAmount: AnglerMoney(amount: 59, currencyCode: "USD")),
            merchandise: AnglerProductVariant(
                id: "41234567890",
                price: AnglerMoney(amount: 29.5, currencyCode: "USD"),
                product: AnglerProduct(id: "7012345678", title: "Linen Shirt"),
                sku: "LS-BLU-M",
                title: "Blue / M"
            ),
            quantity: 2
        )
    )
)
```
