# AnglerImage

An image of the product variant (or of the product, if the variant has none).

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `src` | string | The location of the image as a URL. |

## Example

**Swift**

```swift
let image = AnglerImage(src: "https://cdn.example.com/linen-shirt-blue.jpg")
```

**Kotlin**

```kotlin
val image = AnglerImage(src = "https://cdn.example.com/linen-shirt-blue.jpg")
```

**React Native (TypeScript)**

```ts
const image: AnglerImage = { src: 'https://cdn.example.com/linen-shirt-blue.jpg' };
```

**Flutter (Dart)**

```dart
const image = AnglerImage(src: 'https://cdn.example.com/linen-shirt-blue.jpg');
```

**JSON sent**

```json
{
  "src": "https://cdn.example.com/linen-shirt-blue.jpg"
}
```
