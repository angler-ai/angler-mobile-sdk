# AnglerCheckoutLineItem

One line of a checkout: a variant, its quantity and any discounts on it.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `discountAllocations` | list of [AnglerDiscountAllocation](../discount-allocation/README.md) | The discounts that have been applied to the checkout line item by a discount application. |
| `id` | string | A globally unique identifier. |
| `quantity` | number | The quantity of the line item. |
| `sellingPlanAllocation` | [AnglerSellingPlanAllocation](../selling-plan-allocation/README.md) | The selling plan associated with the line item and the effect that each selling plan has on variants when they're purchased. |
| `title` | string | The title of the line item. Defaults to the product's title. |
| `variant` | [AnglerProductVariant](../product-variant/README.md) | Product variant of the line item. |

## Example

**Swift**

```swift
let checkoutLineItem = AnglerCheckoutLineItem(
    discountAllocations: [
        AnglerDiscountAllocation(
            amount: AnglerMoney(amount: 5.9, currencyCode: "USD"),
            discountApplication: AnglerDiscountApplication(
                title: "SUMMER10",
                type: "DISCOUNT_CODE",
                value: .pricingPercentageValue(AnglerPricingPercentageValue(percentage: 10))
            )
        )
    ],
    id: "li-1",
    quantity: 2,
    title: "Linen Shirt",
    variant: AnglerProductVariant(
        id: "41234567890",
        price: AnglerMoney(amount: 29.5, currencyCode: "USD"),
        product: AnglerProduct(id: "7012345678", title: "Linen Shirt"),
        sku: "LS-BLU-M",
        title: "Blue / M"
    )
)
```
