# AnglerCustomer

A customer: the signed-in shopper, or someone who just registered. Email, phone, name and ID help match app activity to ad clicks, so send what you have.

Sent as `data.customer`. Usually sent with `registration_completed`, `logged_in`.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `id` | string | A unique identifier for the customer. |
| `email` | string | The customer's email address. |
| `firstName` | string | The customer's first name. |
| `lastName` | string | The customer's last name. |
| `ordersCount` | number | The number of orders associated with this customer. |
| `phone` | string | The unique phone number (E.164 format) for this customer. |
| `dob` | string | The customer's date of birth. |
| `hashedEmail` | string | Hashed value of email in SHA256 (lower case). |
| `hashedPhone` | string | Hashed value of phone in SHA256 (lower case). |
| `hashedFirstName` | string | Hashed value of first name in SHA256 (lower case). |
| `hashedLastName` | string | Hashed value of last name in SHA256 (lower case). |
| `hashedDob` | string | Hashed value of date of birth in SHA256 (lower case). |

## Example

**Swift**

```swift
Angler.track(
    .registrationCompleted,
    data: AnglerData(
        customer: AnglerCustomer(
            id: "6012345678",
            email: "jane@example.com",
            firstName: "Jane",
            lastName: "Doe",
            ordersCount: 3,
            phone: "+15555550123"
        )
    )
)
```
