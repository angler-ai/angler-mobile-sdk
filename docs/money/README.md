# AnglerMoney

An amount of money and its currency.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `amount` | number | Decimal money amount. In the currency's main unit: `29.99`, not `2999`. |
| `currencyCode` | string | Currency of the money. An ISO 4217 code, for example `USD`. |
