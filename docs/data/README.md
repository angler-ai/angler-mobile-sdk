# AnglerData

An event's data: the commerce objects it refers to, plus your own name/value pairs. Every field is optional; set the ones that fit the event and leave out the rest.

The `data` of every event: `track`'s `data` argument.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `cart` | [AnglerCart](../cart/README.md) | The cart, for `cart_viewed`. |
| `cartLine` | [AnglerCartLine](../cart-line/README.md) | Represents information about the merchandise in the cart. |
| `checkout` | [AnglerCheckout](../checkout/README.md) | The checkout, for the checkout events and `payment_info_submitted`. |
| `collection` | [AnglerCollection](../collection/README.md) | The collection viewed, for `collection_viewed`. |
| `productVariant` | [AnglerProductVariant](../product-variant/README.md) | Product variant of the line item. |
| `searchResult` | [AnglerSearchResult](../search-result/README.md) | The search, for `search_submitted`. |
| `customer` | [AnglerCustomer](../customer/README.md) | The customer, for `registration_completed` and `logged_in`. |
| `form` | [AnglerFormElement](../form-element/README.md) | The form, for `form_submitted`. |
| `contacts` | list of [AnglerCustomer](../customer/README.md) | Other people the event refers to, in the same shape as `customer`. |
| `customData` | list of [AnglerCustomValue](../custom-value/README.md) | Your own name/value pairs; a custom event's details go here. `track`'s `properties` argument adds to it. |

## Example

**Swift**

```swift
Angler.track(
    .productAddedToCart,
    data: AnglerData(
        cartLine: AnglerCartLine(
            cost: AnglerCartLineCost(totalAmount: AnglerMoney(amount: 59, currencyCode: "USD")),
            merchandise: AnglerProductVariant(
                id: "41234567890",
                price: AnglerMoney(amount: 29.5, currencyCode: "USD"),
                product: AnglerProduct(id: "7012345678", title: "Linen Shirt"),
                sku: "LS-BLU-M",
                title: "Blue / M"
            ),
            quantity: 2
        ),
        customData: [AnglerCustomValue(name: "source", value: "home_banner")]
    )
)
```
