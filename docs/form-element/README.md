# AnglerFormElement

A form the shopper submitted, sent with `form_submitted`.

Sent as `data.form`. Usually sent with `form_submitted`.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `id` | string | The id attribute of an element. |
| `action` | string | The action attribute of a form element. |
| `elements` | list of [AnglerInputElement](../input-element/README.md) | The form's inputs. |

## Example

**Swift**

```swift
Angler.track(
    .formSubmitted,
    data: AnglerData(
        form: AnglerFormElement(
            id: "newsletter",
            action: "/contact#newsletter",
            elements: [
                AnglerInputElement(
                    id: "newsletter-email",
                    name: "contact[email]",
                    tagName: "INPUT",
                    type: "email",
                    value: "jane@example.com"
                )
            ]
        )
    )
)
```
