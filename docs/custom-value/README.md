# AnglerCustomValue

A name/value pair of your own. Both are strings.

Sent as `data.customData` (a list).

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `name` | string | **Required.** The name. |
| `value` | string | **Required.** The value, as a string. |

A custom event (any name that isn't a standard event) is sent as `custom_event`, with its name in `custom_event_name`. Its details go in `customData`.

## Example

**Swift**

```swift
Angler.track(
    .custom("wishlist_added"),
    data: AnglerData(
        customData: [
            AnglerCustomValue(name: "wishlist_id", value: "w-123"),
            AnglerCustomValue(name: "source", value: "home_banner")
        ]
    )
)
```

**Kotlin**

```kotlin
Angler.track(
    AnglerEvent.Custom("wishlist_added"),
    AnglerData(
        customData = listOf(
            AnglerCustomValue(name = "wishlist_id", value = "w-123"),
            AnglerCustomValue(name = "source", value = "home_banner"),
        ),
    ),
)
```

**React Native (TypeScript)**

```ts
Angler.track(
  'wishlist_added',
  {
    data: {
      customData: [
        { name: 'wishlist_id', value: 'w-123' },
        { name: 'source', value: 'home_banner' },
      ],
    },
  },
);
```

**Flutter (Dart)**

```dart
await Angler.track(
  const AnglerEvent.custom('wishlist_added'),
  data: const AnglerData(
    customData: [
      AnglerCustomValue(name: 'wishlist_id', value: 'w-123'),
      AnglerCustomValue(name: 'source', value: 'home_banner'),
    ],
  ),
);
```

**JSON sent**

```json
{
  "customData": [
    {
      "name": "wishlist_id",
      "value": "w-123"
    },
    {
      "name": "source",
      "value": "home_banner"
    }
  ]
}
```

## Shortcut: `properties`

`track`'s `properties` argument takes plain string pairs and adds each one to `customData`, so this sends the same name/value pairs as the example above:

**Swift**

```swift
Angler.track(.custom("wishlist_added"), properties: ["wishlist_id": "w-123", "source": "home_banner"])
```

**Kotlin**

```kotlin
Angler.track(
    AnglerEvent.Custom("wishlist_added"),
    properties = mapOf("wishlist_id" to "w-123", "source" to "home_banner"),
)
```

**React Native (TypeScript)**

```ts
Angler.track('wishlist_added', { properties: { wishlist_id: 'w-123', source: 'home_banner' } });
```

**Flutter (Dart)**

```dart
await Angler.track(
  const AnglerEvent.custom('wishlist_added'),
  properties: {'wishlist_id': 'w-123', 'source': 'home_banner'},
);
```
