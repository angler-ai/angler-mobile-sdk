# AnglerCollection

A collection or category the shopper viewed, sent with `collection_viewed`.

Sent as `data.collection`. Usually sent with `collection_viewed`.

[All data objects](../README.md)

## Fields

Every field is optional unless it says **Required**. Leave out what you don't have.

| Field | Type | Description |
|---|---|---|
| `id` | string | A globally unique identifier. |
| `title` | string | The collection’s name. |
| `productVariants` | list of [AnglerProductVariant](../product-variant/README.md) | The variants shown in the collection; the first page is enough. |

## Example

**Swift**

```swift
Angler.track(
    .collectionViewed,
    data: AnglerData(
        collection: AnglerCollection(
            id: "289012345",
            title: "Summer",
            productVariants: [
                AnglerProductVariant(
                    id: "41234567890",
                    price: AnglerMoney(amount: 29.5, currencyCode: "USD"),
                    title: "Blue / M"
                ),
                AnglerProductVariant(
                    id: "41234567891",
                    price: AnglerMoney(amount: 29.5, currencyCode: "USD"),
                    title: "White / M"
                )
            ]
        )
    )
)
```
